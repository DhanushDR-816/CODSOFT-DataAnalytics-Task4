# CODSOFT Data Analytics Internship – Task 4

## Customer Data Analysis

### Dataset

**UCI Online Retail II Dataset**

The cleaned dataset from Task 1 was used for customer purchasing behavior analysis.

### Objective

- Analyze customer purchasing behavior
- Segment customers based on purchasing patterns
- Analyze customers by location
- Identify valuable customer groups
- Create visual reports to summarize customer insights
- Suggest marketing strategies based on the analysis

### Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

### Analysis Performed

- Analyzed customer purchase value
- Calculated customer order frequency
- Calculated average order value
- Segmented customers into High Value, Regular, and Low Value groups
- Analyzed customer distribution by country
- Compared customer spending with order frequency
- Compared order frequency with average order value
- Created customer behavior visualizations
- Identified valuable customer groups
- Developed marketing strategies based on customer behavior

### Visualizations Created

- Customer Segments by Number of Customers
- Total Spending by Customer Segment
- Customer Spending vs Order Frequency
- Customer Order Frequency vs Average Order Value
- Top 10 Countries by Number of Customers

### Key Insights

- Customer purchasing behavior varies across different customer segments.
- High Value customers contribute significantly to overall purchase value.
- Order frequency helps identify repeat purchasing behavior.
- Average order value provides additional insight into customer spending patterns.
- The United Kingdom represents the largest customer base among the countries analyzed.
- Customer segmentation can help identify valuable customer groups.
- Location and purchasing behavior provide useful information for targeted marketing.

### Marketing Strategies

- Provide loyalty rewards and exclusive offers to High Value customers.
- Use targeted promotions to encourage Regular customers to purchase more frequently.
- Use relevant offers and recommendations to re-engage Low Value customers.
- Develop location-based campaigns based on customer distribution.
- Use purchasing behavior to support personalized marketing campaigns.

### Dataset Limitation

The UCI Online Retail II dataset does not contain an age field. Therefore, customer segmentation in this project focuses on **location and purchasing behavior**, including spending, order frequency, and average order value.
